# DeepSeekBridge

Windows 上的轻量基于 DeepSeek chat 的阅读助手，可在日常使用时可以作为快速的翻译以及查询工具。

选中文字，或准备好剪贴板内容后，按一次配置好的鼠标键即可查询。普通网页或 PDF 打开或复用 DeepSeek 分屏；空白新标签页直接打开 DeepSeek、粘贴并发送。

不需要 API Key、浏览器扩展（使得在使用浏览器阅读本地文件时也可调用）或常驻服务。不向文字添加提示词，翻译或解释行为取决于你的 DeepSeek 对话设置。

## 下载与使用

在本仓库 **Releases** 下载 `DeepSeekBridge-v1.1.11-win-x64.zip`，解压到你有写入权限的固定目录。

1. 在浏览器中登录 `https://chat.deepseek.com`。
2. 将鼠标按键的“启动程序”指向解压后的 `DeepSeekBridge.exe`。
3. 在 Edge 或 Chrome 中选中文字，或者提前复制好要查询的内容后不选中文字，保持浏览器在前台。
4. 按一次配置好的鼠标键。有选区时优先复制选区，没有选区时使用已有剪贴板文字。程序在当前窗口查询，不依赖默认浏览器。

使用鼠标软件启动效果最佳；在文件管理器中直接双击时，前台可能是文件管理器，程序会提示回到浏览器。

日常使用：**选中文字 → 按鼠标键**，或者 **剪贴板已有文字 → 浏览器前台按鼠标键**。原鼠标宏继续启动同一个 EXE。

- 普通网页或 PDF：保留阅读页面，打开或复用 DeepSeek 分屏。
- 独立空白新标签页：当前标签页直接打开 DeepSeek，不新建分屏。
- 已有 DeepSeek 页面或分屏：继续复用，保留已有布局。

新标签页优先通过窗口标题、原生空地址栏和分屏状态快速判断，结合可读取的页面地址排除冲突；连续两次一致才确认。过渡状态每隔 80 毫秒复查，每轮最多额外等待 240 毫秒，再进入完整检查。支持标准 Edge/Chrome 新标签页、Chrome 第三方搜索引擎新标签页、Edge 在线新标签页及 about:blank。普通自定义主页仍按普通网页处理。

若出现 N01，表示新标签页信息尚未一致：等待页面加载完成；若地址栏有尚未提交的输入，先按 Esc 取消再调用。此时程序停止，不误开分屏或覆盖页面。地址栏自动选中的网址不会作为查询选区。

能识别到选区但复制失败时停止并报错。浏览器未提供选区状态时，尝试复制并等待最多 1.5 秒；剪贴板保持不变则使用原有文字。没有可用文字、内容超长或窗口切换时停止。程序不会清空剪贴板或持续监听选区。

### 分屏与发送

- 已有 DeepSeek 分屏：保留左右位置和宽度，直接填入并发送。
- 新建分屏：尝试将 DeepSeek 放到右侧，宽度目标约 18%；保留最低阅读宽度，并受浏览器限制。
- Edge 首次新建分屏时先准备空白页并返回原阅读标签页；Chrome 新建 DeepSeek 标签页后配对。
- 一次调用最多发送一次；输入框有草稿、目标不明确等情况停止并提示。
- 成功后静默退出。异常显示原因和错误代码；操作超过 10 秒时停止自动化并报告超时。

## 系统要求与兼容性

- Windows x64，.NET Framework 4.x（构建环境使用系统 v4.0.30319 编译器）。
- Edge / Chrome 需支持原生分屏，并开放对应的 Windows UI Automation 控件。
- 浏览器和程序以同等权限运行，通常均不需要管理员权限。
- 基于 Edge 152 和 Chrome 143 环境开发。实际可用性还受浏览器界面语言、版本、缩放和 DeepSeek 页面变化影响；内置名称适配以简体中文和英文为主。

基础分屏与发送流程已有用户实测；v1.1.7 的 Edge 多标签页首次新建分屏修复已通过本次用户实测，尚需扩大实机验证范围。不能保证适配所有版本。若已发送却出现“状态不明确”提示，请先查看对话，不要立即重复调用。

## 性能与本地记录

启动时不再固定等待 400 毫秒，仅在鼠标键或修饰键仍按住时短暂等待松开。程序仅在主动运行时工作，不开机启动、不常驻、不持续监听剪贴板。成功结束后不保留运行进程。DeepSeek 网页自身仍使用浏览器资源。

从 **v1.1.6** 起，记录统一保存在 **`DeepSeekBridge.exe` 所在文件夹的 `logs` 子目录**，不依赖 Codex，也不依赖鼠标软件设置的工作目录。例如解压后的结构为：

```text
DeepSeekBridge/
├─ DeepSeekBridge.exe
├─ README.md
└─ logs/                  # 首次正常运行时自动创建
   ├─ status.txt
   ├─ review-report.txt
   ├─ recent.txt
   └─ maintenance.txt
```

你把程序解压在哪里，运行记录就跟随保存在那里。请先完整解压再运行；目录不可写时会提示 `F01`，不会偷偷改存到其他位置。移动程序时一并移动 `logs` 可以保留运行历史和提醒计时。发布压缩包不附带开发者的运行日志。

| 文件 | 用途 |
|---|---|
| `status.txt` | 最近一次结果、阶段耗时、CPU 时间和峰值工作集 |
| `review-report.txt` | 最近 500 次运行的摘要，不含正文 |
| `recent.txt` | 最近一次发送尝试的指纹，用于 15 秒内防重复 |
| `maintenance.txt` | 每月检查提醒时间 |
| `trace.txt` | 仅使用 `--diagnostics` 时启用的本地诊断记录 |

从首次使用开始，每 30 天在下一次成功调用后提醒检查运行记录。提醒 20 秒后自动关闭，也可点击打开记录文件夹。没有后台定时任务，不自动上传记录。

旧版 v1.1.5 及更早版本使用 Windows 的 `%LOCALAPPDATA%\DeepSeekBridge`，那也不是 Codex 目录。新版不会自动读取或导入旧记录；如需继续保留旧历史，可在程序未运行时手动把旧目录中的记录文件复制到新 `logs` 目录，避免覆盖已有的新记录。

默认摘要不保存剪贴板正文、文献标题或网址。诊断模式可包含界面控件标签，请自行检查后再分享。不要把运行记录提交到公开仓库。

## 源码构建

```powershell
.\development\build.ps1
```

脚本先生成候选程序，运行离线自测，通过后替换根目录 `DeepSeekBridge.exe`。失败时保留现有 EXE。构建使用 Windows 自带 C# 编译器，无 NuGet 依赖。也可运行 `DeepSeekBridge.exe --self-test` 单独验证规则，不会访问浏览器或剪贴板。

v1.1.11 包含 106 项离线检查，覆盖目标网址、输入核对、发送确认、日志目录、选区与剪贴板优先级、新标签页路由、状态过渡和有界等待。本次本地更新已获用户正向反馈；离线检查与单机试用不代表适配所有浏览器环境。
